# Getting Started

Welcome to my personal website. You might notice
that it looks like: [The Rust Programming Language
Docs](https://doc.rust-lang.org/stable/book/index.html). This is because I'm
also using [mdBook](https://rust-lang.github.io/mdBook/index.html) for this
website. It makes it so that I can build my entire website in about in less than
a quarter of a second. This included, generating the html, checking all of the
links, and generating an rss feed.

You might notice that there are [two paths](rss.xml) to my [RSS feed](feed.xml).
This is achieved with a shortcut created via ```ln -s``` picked up by mdBook and
built into the html somehow.
